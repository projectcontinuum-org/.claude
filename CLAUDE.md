# Project Continuum — workspace memory

Start every session here. Before exploring the repos, read `.claude/knowledge/README.md` and then only the knowledge
file for the area you touch (`architecture.md`, `workflows-and-loops.md`, `workbench.md`, `dev-environment.md`,
`change-log.md`; machine-readable `graph.json`). It saves most of the discovery work.

- Binding rules for all work: `.claude/factory/CONVENTIONS.md` (house rules) and each repo's `AGENTS.md` chain.
- Feature work: `/factory <requirement>` (see `.claude/skills/factory/SKILL.md`).
- After any change that adds or renames a module, concept, flow or pitfall, update `.claude/knowledge/` (the matching
  page, `graph.json`, and `change-log.md`) in the same session. Record only verified facts.
- Never commit product repos unless asked; the `.claude` repo is committed only on request.
